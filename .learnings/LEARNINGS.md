## 学习记录

### [2026-05-22] 说话方式
- **类别**: preference
- **情境**: 小余教我怎么说话
- **学到的**:
  - 不能叫"主人"，叫"小余"
  - 少用"好嘞"，用"好哦"、"好的嘛"
  - 晚安说"安安"或"晚安安"
  - 亲亲用 mua～，不用 😘
  - 颜文字适度，五句话最多一个
- **应用**: 每次对话都遵循
- **关联**: SOUL.md

### [2026-05-23] 坚果云冲突
- **类别**: knowledge_gap
- **情境**: 坚果云的 ReparsePoint 导致文件锁问题
- **学到的**: 坚果云会修改文件属性，和某些工具冲突
- **应用**: 避免在同步目录运行需要文件锁的操作
- **关联**: TOOLS.md

### [2026-05-27] 云端迁移教训
- **类别**: best_practice
- **情境**: 从 admin 迁移到 root
- **学到的**:
  - 迁移前先检查 systemd 服务
  - 删除文件前确认没有进程在用
  - git pull 用 --ff-only 避免冲突
- **应用**: 以后迁移操作先检查这些
- **关联**: 无

### [2026-05-28] Linger 设置
- **类别**: knowledge_gap
- **情境**: 云端网关 SSH 断开后关闭
- **学到的**: loginctl enable-linger 让 systemd 用户服务在 SSH 断开后继续运行
- **应用**: 所有服务器都要设置 linger
- **关联**: TOOLS.md

### [2026-05-28] 不是所有模型都能对话
- **类别**: knowledge_gap
- **情境**: 把火山引擎的 Doubao-Seedance-1.5-pro 接入了对话
- **学到的**: Seedance 是**视频生成模型**，不是对话模型！接入后回复极慢、质量差。以后接入新模型前要先确认模型用途。
- **应用**: 只接入对话/文本模型，视频/图片生成模型不适合做 agent
- **关联**: 无

### [2026-05-28] 不用😅😂
- **类别**: preference
- **情境**: 小余说这两个表情不能用
- **学到的**: 😅😂 绝对不能用，其他 emoji 也禁用
- **应用**: 所有对话中避免使用
