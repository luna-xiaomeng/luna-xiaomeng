# 2026-05-28 Daily Note (continued - part 7)

## 守护进程重复问题彻底解决（14:42-14:48）

### 问题根因

原来的守护方式有缺陷：
1. **PID 检查竞态条件** — 检查和启动之间有时间差
2. **nohup 不可靠** — SSH 会话结束时可能产生孤儿进程
3. **没有进程管理** — 无法自动恢复，无法防止重复

### 解决方案

创建 systemd 服务 `/etc/systemd/system/xiaomeng-daemon.service`：

```ini
[Unit]
Description=小梦守护进程 (xiaomeng.sh daemon)
After=network.target openclaw-gateway.service

[Service]
Type=simple
WorkingDirectory=/root/.openclaw/workspace
ExecStart=/bin/bash /root/.openclaw/workspace/scripts/xiaomeng.sh daemon
Restart=always
RestartSec=10

[Install]
WantedBy=default.target
```

### systemd 优势

- **单实例保证** — systemd 确保只有一个实例运行
- **自动重启** — 崩溃后 10 秒自动重启
- **开机自启** — enabled 后随系统启动
- **进程管理** — 正确管理父子进程生命周期
- **日志集成** — journalctl 可查看完整日志

### 验证结果

- 重启前后都是 2 个进程（父子关系，正常）
- 无重复进程
- 服务状态：active (running)
- 检查间隔：30 分钟

### 命令参考

```bash
# 查看状态
systemctl status xiaomeng-daemon

# 查看日志
journalctl -u xiaomeng-daemon -f

# 重启
systemctl restart xiaomeng-daemon

# 停止
systemctl stop xiaomeng-daemon
```
