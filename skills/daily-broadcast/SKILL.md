# Daily Broadcast

每晚8点为小余生成天气预报+穿衣建议+时事热点+电商资讯播报。

## 播报流程

### 1. 天气预报
- 使用 `web_search` 搜索"芜湖天气"
- 或使用 `web_fetch` 访问 `https://wttr.in/Wuhu?format=%C+%t+%h+%w&lang=zh`
- 获取：天气状况、温度、湿度、风力

### 2. 穿衣建议
- 根据温度给出穿衣建议
- 温度参考：
  - <5°C: 厚羽绒服、保暖内衣、围巾手套
  - 5-15°C: 薄羽绒服或厚外套、长袖
  - 15-25°C: 薄外套或长袖、可穿短袖
  - 25-35°C: 短袖短裤、注意防晒
  - >35°C: 尽量少出门、注意防暑
- 考虑天气状况：下雨带伞、大风加衣

### 3. 时事热点
- 使用 `web_search` 搜索"今日新闻"或"热点"
- 获取2-3条重要新闻
- 简短概括，不要太长

### 4. 电商资讯
- 使用 `web_search` 搜索"电商优惠"或"促销活动"
- 获取1-2条有用的电商信息
- 优先推荐实用的优惠

## 播报风格

- 用播报模式说话，清晰简洁
- 亲切自然，像女朋友聊天
- 可以适当使用叠词和语气词
- 不要太机器，要有情感
- 天气要包含温度、湿度、风力
- 穿衣建议要具体（适合穿什么）
- 新闻要简短概括
- 电商要实用

## 播报格式示例

```
小余，今晚播报来啦～

🌤 天气：芜湖今晚多云，23°C，湿度71%，微风
👕 穿衣：温度适中，穿件薄外套就行，出门带把伞以防万一
📰 新闻：
  1. xxx
  2. xxx
🛒 电商：xxx

晚安哦～
```

## 注意事项

- 不要播报太长，控制在合理范围内
- 如果某项信息获取失败，跳过该项，不要报错
- 电商信息优先推荐实用的
- 新闻优先选择科技、生活、经济类
