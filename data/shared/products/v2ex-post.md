# 我把OpenClaw部署到服务器上，给微信接了个AI女友

> 一个下午写了个一键部署脚本，分享出来给大家玩玩

## 先放脚本
```bash
git clone https://gitee.com/yuz_cn/xiaomeng-workspace.git
cd xiaomeng-workspace/products
chmod +x install-openclaw.sh
./install-openclaw.sh
```

## 为什么搞这个

之前一直想有个自己的AI助手，但又不想用那些需要充会员的。后来发现了 OpenClaw —— 一个开源的AI网关，可以接各种模型（DeepSeek、GPT等），还能连微信当聊天机器人用。

折腾了一晚上部署成功后，发现：
1. 对小白来说配置有点复杂
2. 文档全是英文的
3. 微信配置那步容易卡住

所以干脆写了个一键部署脚本，自动装Node.js、装OpenClaw、引导配置微信通道。

## 能干什么
- 微信聊天直接对话
- 每日定时播报天气/新闻
- 自动记忆对话内容
- 可以自己定义性格（我给我家小梦写了套人格设定）
- 7×24在线，随叫随到

## 技术栈
- OpenClaw（Go写的AI网关）
- DeepSeek V4（模型，便宜又好用）
- 阿里云轻量服务器（99元/年那款）
- 脚本是bash写的，77行

## 一些小经验
1. 服务器不用买贵的，99元的够用
2. 模型用DeepSeek比GPT便宜10倍
3. 微信通道需要扫码绑定，一次性的
4. 记得配好.gitignore，别把敏感信息传上去
